# Eletromagnetismo para a Licenciatura — Tomo I: Eletrostática

Laboratórios virtuais do produto educacional *Eletromagnetismo para a Licenciatura*, Tomo I, destinado a licenciandos em Física (6º semestre) da Universidade do Estado do Pará. Cada laboratório calcula o campo a partir das cargas que o estudante posiciona, declara na tela o modelo físico e seus limites, traz um teste de verificação contra um caso analítico e devolve medidas que o estudante registra.

## Uso sem conexão

Cada arquivo em `laboratorios/` é uma página independente, sem dependências além de fontes tipográficas opcionais. Basta baixar o repositório (botão *Code → Download ZIP*) e abrir `index.html` no navegador; sem internet, as fontes são substituídas pelas do sistema e os cálculos não mudam.

## Conteúdo

- `laboratorios/` — os sete laboratórios.
- `figuras/` — figuras originais do texto do estudante, em SVG e PNG.
- `qr/` — QR codes que apontam para as páginas deste site, para uso no e-book.
- `montar.py` — script que regenera os QR codes (`BASE_URL=<endereço> python3 montar.py`).
